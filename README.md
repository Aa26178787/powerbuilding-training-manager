# Powerbuilding Training Manager

V1.9 Off-season Powerbuilding + ARM SYSTEM을 기록·추천·일정 관리하는 개인용 모바일 우선 웹/PWA.
모든 데이터는 이 기기의 브라우저(IndexedDB)에만 저장됩니다. 서버·로그인·외부 추적 스크립트가 없습니다.

## 실행

```bash
npm install
npm run dev        # 개발 서버 (http://localhost:5173)
npm test           # 단위·통합 테스트 (계산 엔진, 일정 변경, 달성률, ARM, 저장소)
npm run build      # 타입 검사 → 빌드 → Service Worker 생성 → ARM 원문 번들 검사
npm run preview    # 빌드본 확인 (오프라인 동작은 여기서 확인)
```

휴대폰에서 쓰려면 `dist/`를 HTTPS 정적 호스팅에 올린 뒤 홈 화면에 추가하세요(Service Worker는 HTTPS 또는 localhost에서만 동작).

## 안드로이드에서 쓰기

- Chrome으로 열고 [더보기 → 설정·데이터 → 홈 화면 설치](또는 Chrome 메뉴 ⋮ → 홈 화면에 추가).
- 뒤로가기 버튼: 열린 시트 닫기 → 이전 탭 → 홈 순서로 동작하고, 홈에서 한 번 더 누르면 앱이 닫힙니다.
- 세션 진행 중에는 화면이 꺼지지 않게 유지하고(Wake Lock), 세트 완료 시 짧게 진동합니다. 둘 다 설정에서 끌 수 있습니다.
- 백업 파일은 휴대폰의 다운로드 폴더에 저장됩니다.

## ARM 자료 취급 (필수)

- `ARM_SYSTEM.pdf`와 추출 JSON/CSV는 저작권 보호 자료입니다. **저장소·공개 호스팅·`public/`에 넣지 마세요.**
- 보관은 `private/` 폴더에만 하세요. `.gitignore`가 `private/`와 `ARM_SYSTEM*` 파일, 백업 파일을 막습니다.
- 앱에서는 [ARM] 탭 → "ARM JSON 파일 선택"으로 기기에서 직접 가져옵니다.
- `npm run build`는 마지막에 `scripts/check-bundle.mjs`로 산출물에 ARM 원문이 섞였는지 검사하고, 섞였으면 실패합니다.
- 백업 파일은 기본적으로 ARM 처방 라이브러리를 빼고 내보냅니다. 포함해서 내보낸 파일(`...-with-arm.json`)은 공유하지 마세요.

## 구조

```
src/
  domain/        타입, V1.9 기본 프리셋
  engine/        순수 함수만: e1RM, Backoff, 진행 판정, 계수(EMA), 달성률, 일정 변경, 상태
  application/   유스케이스: 주간 계획 생성, 세트 기록, 일정 변경 트랜잭션, ARM 배정
  repositories/  IndexedDB 어댑터 (트랜잭션, rev 충돌 검사)
  data-import/   ARM JSON 검증, 백업·복원 검증
  ui/            React 화면 (수식·DB 접근 없음)
  tests/         Vitest
```

`engine/`은 React·DOM·IndexedDB·현재 시각에 의존하지 않습니다. 시각·날짜·ID는 `Ctx`로 주입합니다.

## 구현 범위

**기록·계산**
- 프로그램 조회·편집(새 버전은 다음 주부터 적용, 과거 기록 불변)
- 세트 기록, Top Set → Backoff 추천, 세트 간 감량·조기 종료 제안, 선형 증량, Double Progression
- 실패 규칙: 미달 시 유지, 2회 연속이면 유지 또는 2.5~5% 감량 후보(승인 필요), 3회 연속이면 검토 안내
- 워밍업 단계 제안(바벨 운동 첫 세트), 휴식 타이머, 원판 조합 표시

**일정·달성률**
- 주·월 게이지: 원본 계획 달성률, 조정 계획 이행률, 기한 경과분 이행률, 방문 수, ARM Day 이행률
- 이동·맞교환·병합·분할·이월·면제·삭제·세트 추가/축소, 규칙 기반 경고, 근육군별 세트 변화량, 미리보기 후 승인, 취소

**ARM SYSTEM**
- JSON 가져오기, Day 수동 배정(주 3일/2일), 좌·우 별도 기록, 원본 누락 직접 입력, 교정, 영상 링크(HTTPS)

**분석·개인화**
- 개인화 계수 자동 학습(EMA, 1회 ±5% 제한): 관측 기록을 시간순으로 재생해 k를 계산하므로, 각 예측은 그 이전 관측만 사용
- 모델 실험실: 종목별 k, 관측 이력, 개인화 vs 기본(k=1) 예측 오차, 관측 포함/제외, 수동 지정·초기화, λ·제한폭 설정
- 근육군별 가중 세트(주동근 1.0 / 보조근 0.5, 운동별 편집), 운동별 e1RM·중량 추세, 주간 달성률 추이
- 기록 기반 피로 신호(반복되는 상한 초과, 중량 정체 속 RPE 상승, 중량 연속 하락)

**데이터**
- 오프라인 앱 셸, JSON 백업·복원, 수행 기록 CSV 내보내기, 다중 탭 단일 쓰기 권한, IndexedDB 스키마 v2(계수 관측 기록 추가)

## 하지 않은 것

- 서버 동기화·다중 기기(백엔드 필요), 사진·영상 첨부, 대회 준비(피킹) 블록, 병합 후보 자동 최적화
- 워밍업 세트 기록 화면(제안만 표시), 휴식 타이머 알림음

## 명세와 다르게 정한 점

- 프로그램을 편집해도 **이번 주 계획은 바뀌지 않습니다**(주 시작 스냅샷 유지). 이번 주 조정은 이동·세트 추가·축소로 합니다.
- 날짜가 지난 세션은 자동으로 `missed`가 되지 않고 "기한 경과·미확정"으로 남습니다. 캘린더에서 직접 확정합니다.
- 기한 경과분 이행률은 **현재 계획일** 기준입니다(뒤로 옮긴 세트는 그 날짜가 될 때까지 미완료로 세지 않음).
- Variation 첫 시작 중량은 반복 범위 **상단**(예: 8~10회면 10회)과 목표 RPE로 환산합니다.
