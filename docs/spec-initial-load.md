# 최초 중량 산출·반올림 명세 (V1.9 SRS 추가분)

엔진 버전: `initial-load-1.0.0`, e1RM 공식 `e1rm-rts-2.0.0`(RTS 표, 보수적 e1RM). 구현은 `src/engine/initialLoad.ts`, `src/engine/rounding.ts`, 추천 경로는 `src/application/recommend.ts`. 테스트는 `src/tests/initialLoad.test.ts`.

## 1. 최초 중량 산출 순서

추천은 제안이다. 사용자가 고친 중량이 실제 기록이 되고, 원래 추천값은 `Recommendation`에 그대로 남는다.

| 운동 | 1순위 | 2순위 | 3순위 |
|---|---|---|---|
| 대회 SBD Top Set | 다음 세션 중량(진행 판정) | 같은 운동 기록의 e1RM → 목표 반복 @7.5 | 가벼운 세트로 보정 |
| Bench Variation(SnG k 1.000 임시, Larsen 0.925), High-bar 0.925 | 자기 기록 | 대회 종목 e1RM × k_base × k_개인 → 반복 하한 @min(7, 목표 상한) | 가벼운 세트로 보정 |
| Conventional DL | 자기 기록만(Sumo와 독립) | — | 가벼운 세트로 보정 |
| Weighted Dips·Pull-up Volume | 자기 기록 | 같은 운동 Strength의 시스템 e1RM(체중+추가) | 가벼운 세트로 보정 |
| 일반 보조 | 자기 기록 | — | 가벼운 세트로 보정 |
| ARM | PDF %1RM × 등록한 기준 1RM(처방 검증·강도 누락 없음일 때만) | 같은 ROM·실행 변형의 지난 기록만 | 직접 입력 |

- 다른 운동 기록은 `variationOf`·`relatedOf`로 명시된 경우에만 쓴다.
- 체중 운동은 시스템 하중(체중+추가)으로 계산하고 체중을 뺀다. 음수면 보조(밴드·머신)가 필요하다고 안내하며, 보조 세트는 진행 판정과 e1RM에서 뺀다.
- `loadUnit`: `total`(기본), `per_hand`(덤벨 한 손, 총 외부 하중은 ×2), `machine`(스택 표시값, 다른 운동과 환산하지 않음).

## 2. 화면 표시

추천 중량과 함께: 신뢰도(참고 기록 있음 / 추정치 / 기록 없음, 퍼센트 없음), 반올림 메모(`계산값 129.84kg → 130kg (가까운 쪽, 2.5kg 단위)`). "근거"를 열면 산출 방법, 기준 운동, 사용한 e1RM, k_base × k_개인, 목표 반복·RPE, 반올림 모드와 단위, 개인화 보정 여부, Fast-track 여부.

추천과 다른 중량을 넣으면 바꾼 이유(컨디션·장비 차이·기술 연습·통증 주의)를 고를 수 있다(선택). `editReason`으로 저장.

## 3. 가벼운 세트 보정

기록이 없으면 가벼운 세트 하나(중량·반복·RPE)를 넣는다. 보수적 e1RM → 목표 반복 @RPE 중량. 결과는 넣은 세트 중량보다 낮게 추천하지 않는다. 이 세트는 수행 기록이 아니며, 첫 세트를 기록할 때 `kind: 'calibration'` 추천으로 입력값과 함께 남는다. 워밍업 단계 표시 기능은 없다.

## 4. 첫 세션 요약

운동의 첫 진행 판정 때 `exStates.firstSession`에 날짜, 추천 중량, 방법, 신뢰도, 기준 운동, 계수, 실제 중량, 수정 여부, 세트, 다음 중량, 판정을 저장한다.

## 5. 반올림

- 모드: 가까운 쪽(NEAREST, 정확히 중간이면 올림), 내림(FLOOR), 올림(CEIL). 부동소수 오차는 1e-6으로 보정.
- 기본 정책(설정에서 종류별 변경): Top Set·최초 중량·Fast-track은 가까운 쪽, Backoff·RPE 초과 감량·세트 중 증량은 내림.
- 운동별 `roundingOverride`가 정책보다 우선한다.
- 계산 중간에는 반올림하지 않는다. e1RM, 계수, 체중 차감까지 소수로 계산하고 최종 값에서 한 번만 반올림한다.
- 중량 단위(`loadStep`)는 증량 폭(`increment`)과 별개다. 바벨은 보유 원판(수량 반영)으로 만들 수 있는 최소 차이보다 작게 잡지 않는다. 만들 수 없는 중량은 추천하지 않는다.

## 6. Fast-track

Top Set이 목표 RPE보다 가벼웠으면 다음 세션 중량 = max(직전 + 증량, RTS 역산 중량). 둘을 더하지 않는다. 상한은 (직전 + 체중) × (1 + 최대 증가율) − 체중, 기본 5%(설정에서 2.5~10%). 상한은 내림으로 단위에 맞춘다. 같은 기록으로 두 번 적용하지 않도록 근거 세트 id를 결정에 남긴다.
